    数据口径

    输入 Token 对应 prompt_tokens，输出 Token 对应 completion_tokens，总量为二者之和。费用直接累加 spend（USD）。时间戳统一换算为 UTC 日期。

    项目台账按 id 更新，未列出的项目保留。日志按 request_id 去重，已存在的记录保留原值；项目预算和工期为台账当前快照，不随日期筛选变化。

    个人求职展示请始终使用虚构数据。导入后的数据库位于忽略目录，不应加入 Git。
