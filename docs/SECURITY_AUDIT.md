- 非回环 IPv4 地址、非示例邮箱账号、未审核 URL 主机。

确认示例公司、3 个部门、6 位成员、6 个项目、仓库位置、模型别名、提交 SHA 和统计值均为虚构。仓库均使用 example.com 保留示例域名；只有显式启用的公开采集请求固定访问 Gitee 官方主机。localhost 与回环地址是本地运行配置，不是企业服务地址。依赖清单中的上游开源项目链接与许可证元数据不是企业信息。

截图已目视检查，仅展示虚构数据，不使用原业务截图。扫描器不对图片做 OCR，不证明不存在所有未知业务敏感信息；文字语义和权利审核仍需人工完成。

## 配置与运行时保护

- `.env.example` 凭据为空，默认离线，不读取父目录配置。凭据不通过 API 返回。
- Git 忽略真实台账、数据库及其 WAL、密钥、日志、上传、导出、模型权重、虚拟环境与缓存。
- 文件扩展名、上传字节数、解压体积、Excel 工作表、字段类型、非负数、公式与宏均有校验；每批次原子写入。
- 上传原始文件不持久化；JSON 仅保存统计白名单，丢弃提示词、密钥、邮箱和多余元数据。导入后结构化数据仍可能敏感，因此数据库必须留在忽略目录。
- SQL 使用参数绑定。原前端使用字段转义，新工作区使用 textContent；服务器只返回经过校验的数据。
- 只接受本机 Host，限制跨站写入；提供 CSP、nosniff、no-referrer。保留原页面动态样式所需的行内 CSS，登录脚本使用固定哈希放行，不允许任意行内脚本。
- Gitee 固定主机、HTTPS、无重定向、无环境代理，先校验公开性；不保存作者姓名、邮箱、提交消息。分页超限拒绝整个批次。
- 原登录页仅是本地演示，不进行身份认证，不存储密码。原套餐页是虚构快照；模型测速禁用。不可直接作为公网服务。
